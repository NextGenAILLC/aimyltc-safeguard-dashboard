# AiMyLTC SafeGuard™ — Patient Safety & Fall Detection Dashboard

Interactive live demo of AiMyLTC SafeGuard™: AI-powered fall detection, resident monitoring, safety compliance, and device ordering for long-term care facilities.

## Live Demo

Once deployed (Vercel / Netlify / GitHub Pages), this serves as a full product page + live monitoring dashboard ready for prospect demos and advertising.

## Features

- Real-time resident safety dashboard with fall alerts
- Facility zone monitoring
- AI risk predictions
- Compliance scoring
- Response metrics
- Orderable SafeGuard devices (Smart Bracelet, Room Sensor, Hub)
- Dark medical-tech UI optimized for professional LTC audiences

## Deploy

1. Connect this repo to Vercel (recommended) or Netlify for one-click static hosting.
2. Or download `index.html` and drag-drop to any static host.
